# TURZX WPF 迁移与监控主题编辑器设计

## 技术选型

- 界面框架：Windows Presentation Foundation（WPF）。
- UI 组件库：WPF UI 4.3.0，MIT 许可。
- 目标框架：.NET Framework 4.7.2；Windows 已安装的 4.8 运行时可直接运行。
- 构建：便携式引用程序集 + Windows 自带 MSBuild，不要求安装 Visual Studio 或 .NET SDK。
- 稳定后端继续复用：WinUSB 通信、TURZX 协议、PNG 画面传输、FFmpeg 视频解码、LibreHardwareMonitor。
- 旧 WinForms 程序暂时保留在 `artifacts` 根目录，用于迁移期间回退。

## 主界面结构

固定窗口由左侧导航和右侧内容页组成：

1. 系统信息：设备状态、3:1 屏幕预览、输出协议和实时概览。
2. 图片显示：选择图片、适配方式、自定义拖动/滚轮缩放、0°/90°/180°/270°手动旋转和 USB 发送。
3. 视频播放：选择视频、方向归一化预览、手动旋转、自定义拖动/缩放裁剪、帧率/循环设置、USB 播放与停止。
4. 监控主题编辑器：背景、组件、画布、图层、属性，以及实时显示的开始/停止。
5. 常用传感器：只显示监控主题通常会使用的数据源，并保留多个有意义的 CPU 温度来源。
6. 设置：系统/浅色/深色外观、硬件传感器权限以及迁移信息。

## 监控主题工程

主题文件扩展名为 `.turzxtheme.xml`，包含主题名称、背景类型、背景路径、背景颜色、有序组件图层，以及每个组件的类型、名称、内容、语义监控项、位置、尺寸、字体和颜色。旧主题中保存的传感器 ID 会在载入时自动迁移，不需要重新制作主题。

程序关闭时会把当前主题保存到 `%APPDATA%\TurzxControl\themes\default.turzxtheme.xml`，下次启动自动恢复。编辑器也支持另存和打开其他主题文件。

## 960 × 320 编辑画布

编辑画布始终保持物理屏幕的 960 × 320 坐标系。窗口只是等比例缩放显示，因此主题文件中的位置和尺寸不受 Windows DPI 或窗口缩放影响。

当前组件包括文字、时间、天气、监控数值和监控进度条。组件可直接拖动。“添加组件”“屏幕画布”“图层”位于同一顶行，图层与画布卡片等高；属性卡片横向排列在画布下方，卡片之间统一使用 12px 间距。属性区可以精确编辑名称、内容、语义监控数据、字体、水平/垂直对齐、X/Y、宽高、四边文字边距、文字颜色、背景及描边的颜色与透明度、描边粗细和圆角；颜色通过带实时色块的完整可视化色谱选择器设置，不再要求输入十六进制数字。字号、透明度、坐标、尺寸、边距、描边和圆角均使用数字输入框，同时支持按住鼠标左右拖动连续调整。相同的外观参数同时用于编辑预览和实际屏幕输出。

每个图层前方都有眼睛按钮，可直接显示或隐藏组件；隐藏图层会在列表中降低透明度并切换为闭眼图标。画布不会额外绘制蓝色选中边框或光晕，确保组件自己的文字、背景和描边颜色始终能够被准确判断。界面中需要滚轮滚动的区域仍支持滚轮操作，但不显示右侧滚动条。

## 背景

- 照片：PNG、JPEG、BMP，按画布裁剪铺满。
- 视频：MP4、WMV、AVI、MOV，编辑器中静音循环预览。
- 纯色：当前默认深蓝黑色，模型保存颜色字段。

“开始实时显示”使用独立的固定节拍：计时器和完整主题画面以 4 FPS 渲染并通过 WinUSB 写入屏幕，传感器仍以 1 Hz 在后台采集。计时输出不再等待硬件传感器采集完成，因此不会因采集耗时额外延迟并跳过秒数。切换软件页面不会中断输出；点击“停止”，或开始图片/视频输出时才会释放屏幕。视频背景与监控图层的高帧率合成仍属于下一阶段。

## 天气配置

设置页支持配置城市、摄氏/华氏温标及 5、15、30、60 分钟更新间隔。“保存并获取天气”会通过 Open-Meteo 地理编码接口把城市解析为经纬度，再获取当前温度和天气代码；天气代码会转换为中文天气描述并用于编辑器预览和实时屏幕输出。配置保存在 `%APPDATA%\TurzxControl\weather.xml`，天气请求失败时不会影响传感器或 USB 主题刷新。

## 传感器目录

新数据模型把“监控项”和“硬件传感器”分开。主题组件保存 CPU 温度、CPU 使用率、CPU 功耗、GPU 温度、内存使用率等稳定的语义监控项；设置页再把这些项目统一映射到 LibreHardwareMonitor 的具体 Identifier。CPU 温度会优先选择 CPU Package，用户也可在设置中改为 Core Average、Core Max 等来源，所有引用该监控项的主题组件会同步切换。

传感器映射保存在 `%APPDATA%\TurzxControl\sensor-mappings.xml`，与主题文件分离。因此主题可以复制到不同硬件上，再针对该电脑选择对应传感器，不会把某台电脑的 Identifier 固化进主题设计。

当前测试机的硬件库原始发现 184 个传感器，新常用目录会过滤重复的每核心负载、Distance to TjMax、大量电压与底层调试通道；CPU Package、Core Max、Core Average 仍可分别选用。

温度、功耗和电压读取已经拆分为普通权限界面与 `LocalSystem` 后台服务。界面通过版本化的本机命名管道请求只读快照，管道只接受本机进程，并只给认证用户最小的连接、读写和同步权限；服务不接受任意文件、命令或硬件写入请求。服务位于 `artifacts\wpf\sensor-service` 独立目录，运行时不会锁住主界面依赖，因此可以单独升级界面。

LibreHardwareMonitor 0.9.6 使用 PawnIO 读取 MSR 等底层寄存器。设置页的“安装驱动与服务”会先展示风险说明，用户确认后在一次 UAC 中从官方 LibreHardwareMonitor 发行包提取并静默安装原装 PawnIO，再创建自动启动服务。执行前会把安装程序的 SHA-256 与本版本固定值 `A3A46226C5E2824F4CDD42BE0EECBABFC672C86F7889710F5AB1E6AD385B47A0` 比对；当前文件的 Authenticode 签名者为 `namazso.eu` 且验证有效。任何资源替换或损坏都会导致安装被拒绝。软件不会把 PawnIO 设备直接开放给普通用户。卸载 TURZX 服务不会自动卸载可能被其他监控软件共用的 PawnIO；需要时可从 Windows“已安装的应用”中单独移除。服务未安装、未运行或驱动不可用时，界面自动退回 CPU 使用率、内存、磁盘、网络和运行时间等 Windows 基础数据。

## 图片自定义构图

WPF 图片页使用固定 960 × 320 画布和 GPU 渲染变换。选择“自定义拖动缩放”后以完整图片为初始状态，可直接拖动画面并用滚轮缩放；交互过程不重新编码原图。发送时才把当前画布渲染为最终 PNG，因此预览跟手且发送结果与画布一致。图片和视频均提供0°、顺时针90°、180°和顺时针270°手动旋转。

竖向的面板传输素材会先归一化到逻辑横向坐标，确保软件预览与物理屏幕方向一致；用户选择的旋转在归一化之后应用。视频自定义模式同样从完整画面开始，拖动、缩放和旋转参数会进入 FFmpeg 逐帧滤镜，因此本地预览和 USB 输出使用同一套构图。

实时主题渲染会在截图前强制完成组件测量和布局，并使用适合位图输出的灰度文字渲染；编辑器的蓝色选中框会在生成输出帧时临时隐藏，避免只发送到边框而丢失新建文字。
